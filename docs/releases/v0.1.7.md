# Grok Build Desktop v0.1.7

发布日期：2026-08-28

本次版本集中完善了扩展生态管理能力：插件市场、MCP 和 Skills 现在可以在桌面端完成发现、配置、安装、更新、诊断与卸载。同时升级了内置终端和会话批量操作，并修复插件市场快速切换 Tab 时可能导致桌面端退出的稳定性问题。

## 重点更新

### 插件市场与插件生命周期

- 新增完整的插件市场界面，可按市场源浏览和筛选插件，并直接重读本地目录或同步远程来源。
- 支持添加、更新和移除 GitHub 仓库、Git URL 与本地目录形式的市场源。
- 支持通过市场插件名、Git URL、`owner/repo`、本地目录以及带 `@ref`、`#subdir` 的来源安装插件。
- 支持单个或全部插件更新、卸载，以及卸载时保留插件数据。
- 安装后会自动检查插件声明的 MCP 与运行环境；任何安装、依赖补齐、认证或运行验证失败都会尝试回滚本次安装。
- Windows 下可识别插件缺少的 `uvx` 运行环境，并通过 winget 安装 `uv`；安装后会自动补充可执行路径。
- 新增插件开发工具，可校验 manifest，并按 manifest 版本预览、创建或推送 Git 标签。
- 插件卡片现在会展示来源、版本、组件清单、运行依赖和可用状态等信息。

### Windows 市场兼容

- 新增市场兼容镜像，可读取 Grok、Claude 与 Codex marketplace 清单。
- 自动处理 Windows 不兼容的路径字符、大小写差异、扁平 Skill 文件和旧式组件目录。
- 支持解析远程插件仓库、分支或提交及子目录，并将其转换为 Grok 可安装的本地结构。
- 自动补齐 `.grok-plugin/plugin.json`；上游清单引用不存在的组件时会跳过并给出说明。

### MCP 管理

- 新增 MCP 管理页，同时展示磁盘配置与当前 Grok 会话中的实时状态。
- 支持添加或更新 `stdio`、HTTP 和 SSE 服务器。
- 支持配置命令参数、环境变量、HTTP Headers、Bearer Token 环境变量、OAuth Client 信息与 Scopes。
- 支持启动超时、默认工具超时和单工具超时配置，并在更新高级字段时保留其他 TOML 配置。
- 支持启用或停用服务器、按工具单独开关、OAuth 认证、初始化字段提交和健康诊断。
- 改进实时状态、错误、认证需求和工具列表的映射，兼容 Grok ACP 扩展方法的新旧命名空间。
- 对参数边界、URL、环境变量、Header、Scope 和超时进行更严格的输入校验。

> MCP 的 OAuth 认证、初始化和实时工具控制需要先打开一个对话，以便使用当前 Grok 会话。

### Skills 管理

- 扩展 Skills 发现范围，覆盖项目与用户的 `.grok`、`.agents`、Claude、Cursor、托管目录、插件目录和额外搜索路径。
- 同名 Skill 不再被覆盖，并保留来源、限定调用名、模型、允许工具、调用方式和插件版本等元数据。
- 支持添加、移除和重置额外搜索路径，查看忽略路径，以及启用或停用 Skill。
- 支持在用户级或项目级目录创建标准 `SKILL.md`，可填写描述、参数提示、允许工具、模型及调用选项。
- 创建操作会限制在受支持的 Skills 目录内，并拒绝覆盖已有文件。

### 终端与会话操作

- 内置终端升级为基于 xterm.js 与 PTY 的真实交互终端，支持完整键盘输入、ANSI/True Color 输出和窗口自适应缩放。
- 改进终端进程的尺寸同步、退出状态和资源清理。
- 会话侧边栏支持 `Ctrl/Cmd` 多选与 `Shift` 连续选择。
- 多选后可批量分叉或删除会话，并增加批量操作的失败提示和选择状态清理。

### 连接与模型体验

- OAuth 模式下不再显示桌面端 API 专用的自定义模型，避免切换连接方式时误选或污染 OAuth 配置。
- 保留 API 与 OAuth 各自的模型和凭据状态，继续兼容旧版 API 配置迁移。

## 稳定性修复

- 修复在插件市场、MCP 与 Skills 之间快速来回切换时，重复刷新和卸载后的异步回写可能触发桌面端闪退的问题。
- 同一上下文中的重复 Tab 加载现在会合并请求并复用成功结果；手动刷新、轮询和扩展变更仍会强制获取最新数据。
- 页面切换、卸载或项目上下文变化后，过期请求不再更新当前界面。
- MCP 验证、认证等内部探测会话不再出现在会话列表中。
- 改进 ACP 扩展请求失败时的兼容回退，以及 MCP 初始化、认证失败和超时状态的识别。
- 改进远程市场下载、路径解析和插件清单转换在 Windows 上的容错。

## 工程与测试

- 新增插件命令、安装事务、MCP 配置与运行态、Skills 创建与发现、扩展界面及 Tab 刷新并发控制测试。
- 测试范围覆盖插件安装失败回滚、MCP OAuth/初始化、运行依赖检测、Windows 市场兼容、Skill 路径安全和快速 Tab 切换等关键路径。
- 验证结果：TypeScript 类型检查通过，92 项自动化测试通过，生产构建通过。
- 新增 `@xterm/xterm`、`@xterm/addon-fit` 与 `node-pty` 依赖，为交互终端提供支持。

## 升级说明

- 本版本无需手动迁移现有配置；原有 Grok、MCP、Skills 与市场源配置会继续读取。
- 安装包含 Hooks、MCP 或可执行脚本的第三方插件前，请确认来源可信。
- 若 Windows 系统未安装 winget，缺少 `uvx` 时需要手动安装 `uv`。
